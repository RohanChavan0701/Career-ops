No professional summary section on CV. Rohan considers it redundant.

**Why:** User preference — let the bullets speak.

**How to apply:** When generating CVs (pdf or latex mode), skip the summary section entirely. Go straight to Education -> Skills -> Experience -> Projects -> Achievements. Use the LaTeX format Rohan provided (10pt Times, tight margins, his exact preamble) not the HTML template.

Also: CV must fit 1 page. Never generate 2-page CVs.
